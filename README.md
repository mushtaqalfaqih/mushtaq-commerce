## 🌟 نظرة عامة على المشروع

**بازاري مشتاق (Bazaary Mushtaq)** هو تطبيق متجر إلكتروني متكامل للجوّال مبني بأحدث معايير **Flutter 3** وتصميم **Material 3**. 
يتميز التطبيق بدعم أصيل كامل للغة العربية والاتجاه من اليمين إلى اليسار (**RTL-First**)، مع توفير تجربة تسوق غنية تشمل السلايدرات المتحركة، عروض الفلاش بالعدادات التنازلية الرقمية الحية، شاشات المتاجر المخصصة للمؤثرين، وسلة تسوق تفاعلية بالكامل تعمل محلياً دون الحاجة لاتصال إنترنت.

---

## 🚀 أبرز المميزات والوظائف

### 1. 🎨 الواجهة الرئيسية والتنقل (Home & Discovery)
* **ترويسة رأسية متدرجة (Gradient Header):** تدرج لوني انسيابي يدمج محدد الموقع الجغرافي (صنعاء - الأمانة) مع حقل بحث تفاعلي عائم.
* **سلايدر إعلانات ذكي (Auto-Sliding Carousel):** شريط بانرات متحرك كل 4 ثوانٍ مع مؤشرات نقاط ديناميكية قابلة للتفاعل والسحب اليدوي.
* **قائمة فئات أفقية بصفين (Two-Row Category Rail):** استعراض سلس للأقسام الرئيسية مع بطاقات أيقونات ملونة وظلال ناعمة.

### 2. ⚡ عروض الفلاش التنازلية (Live Flash Sale)
* **عداد تنازلي حي ينبض بالثواني (Live Countdown Ticker):** مؤقت رقمي بنمط منصات التجارة الكبرى (أمازون ونون) يعرض الساعات، الدقائق، والثواني مع وميض حي.
* **مؤشر نفاذ الكمية (Stock Progress Bar):** شريط مرئي تفاعلي يوضح نسبة المنتجات المباعة لكل عرض استعجالي.

### 3. 👑 متاجر المؤثرين التفاعلية (Influencer Store Hubs)
* **متاجر مخصصة للشركاء:** بوابات تسوق خاصة بالمؤثرين (**مشتاق الفقية** و**حنان فازع**).
* **كوبونات خصم حصرية:** كود خصم مخصص بنقرة نسخ واحدة (`MUSHTAQ15` و `HANAN15`).
* **مختارات حصرية:** عرض المنتجات التي يوصي بها المؤثر شخصياً مع شارات توثيق رسمية.

### 4. 🔍 البحث الذكي ومعالجة اللغة العربية (Normalized Live Search)
* **تصفية حية وفورية (Instant Live Filtering):** تظهر النتائج لحظياً أثناء كتابة الحروف دون الحاجة لضغط زر الإدخال.
* **معالجة النصوص العربية:** خوارزمية تطابق مرنة تتجاهل الفروق بين الهمزات (`أ/إ/آ/ا`) والتاء المربوطة والهاء (`ة/ه`) والياء والألف المقصورة (`ي/ى`).

### 5. 🛒 سلة المشتريات التفاعلية (Interactive Cart & Checkout)
* **نافذة الإضافة المنزلقة (Custom Frosted Bottom Sheet):** إشعار سفلي فخم يرتفع بنعومة عند إضافة أي منتج مع ملخص السعر وزري "متابعة التسوق" أو "الدفع".
* **تحكم بالكميات:** زيادة وإنقاص وحذف فوري مع حساب المجموع الفرعي ورسوم التوصيل تلقائياً.
* **إتمام الطلب التفاعلي:** شاشة تأكيد الطلب مع كود تتبع للشحنة ونافذة نجاح جذابة.

### 6. ❤️ قائمة المفضلة المتصلة (Wishlist System)
* زر مفضلة سريع في زوايا كروت المنتجات وتفاصيلها.
* شاشة مخصصة للمفضلة تتيح نقل المنتجات مباشرة إلى السلة أو استعراض تفاصيلها.

### 7. 🎭 حركات وتفاعلات سينمائية (Micro-Interactions)
* **حركة التكبير السلسة (Hero Transitions):** طيران وتمدد صور المنتجات من الكرت إلى شاشة التفاصيل بدون أي قفزات.
* **ارتداد اللمس (Tactile Spring Bounce):** انضغاط الكروت بنسبة 5% عند ملامسة الإصبع وارتدادها بحيوية فائقة.

## 🏗️ الهيكلية المعمارية للكود (Architecture)

تم بناء المشروع باتباع مبادئ **Clean Code** وفصل المسؤوليات لضمان سهولة الصيانة والتوسع:

```text
bazaary_app/
├── android/                     # إعدادات منصة أندرويد والأيقونات عالية الدقة
├── images/                      # الأصول البصرية، البانرات وصور المنتجات
│   ├── app_icon.jpg             # أيقونة التطبيق الرسمية ثلاثية الأبعاد
│   └── ...                      # صور المنتجات والبانرات
├── lib/
│   ├── data/
│   │   └── mock_data.dart       # مصادر البيانات والمنتجات الافتراضية
│   ├── models/
│   │   ├── cart_item.dart       # نموذج بيانات عنصر سلة المشتريات
│   │   └── product.dart         # نموذج بيانات المنتج مع حساب الخصومات
│   ├── screens/
│   │   ├── cart_screen.dart     # شاشة السلة الذكية وتأكيد الطلب
│   │   ├── categories_screen.dart # شاشة استعراض كافة الفئات
│   │   ├── influencer_store_screen.dart # شاشة متجر المؤثر المخصص
│   │   ├── offers_screen.dart   # شاشة الكوبونات والعروض الترويجية
│   │   ├── product_details_screen.dart # شاشة مواصفات وتفاصيل المنتج
│   │   ├── profile_screen.dart  # شاشة الحساب والبيانات الشخصية
│   │   └── wishlist_screen.dart # شاشة قائمة المنتجات المفضلة
│   ├── widgets/
│   │   ├── add_to_cart_bottom_sheet.dart # النافذة المنزلقة لتأكيد السلة
│   │   ├── banner_carousel.dart # سلايدر البانرات الدوار التلقائي
│   │   ├── bottom_bar.dart      # شريط التنقل السفلي مع شارة العداد
│   │   ├── flash_sale_section.dart # قسم عروض الفلاش مع العداد الحي
│   │   ├── home_header.dart     # الترويسة العليا وشريط البحث الحي
│   │   └── product_card.dart    # بطاقة المنتج التفاعلية بحركة Hero
│   └── main.dart                # مدخل التطبيق وإدارة الحالة العامة
├── pubspec.yaml                 # حزم المشروع والتبعيات وإعدادات الخطوط
└── README.md                    # التوثيق التقني للمشروع
```

## 🛠️ التقنيات والمكتبات المستخدمة

| التقنية / الأداة | الغرض والاستخدام |
| :--- | :--- |
| **Flutter SDK (v3.8+)** | إطار العمل الأساسي لبناء واجهة المستخدم متعددة المنصات |
| **Dart Language** | لغة البرمجة الرئيسية مع معايير Null Safety الصارمة |

## 💻 دليل التثبيت والتشغيل المحلي

### 1. المتطلبات المسبقة
* تثبيت بيئة **Flutter SDK** (إصدار 3.8 أو أحدث).
* تثبيت **Android Studio** أو **VS Code** مع إضافات Flutter & Dart.

### 2. استنساخ المستودع (Clone)
```bash
git clone https://github.com/<your-username>/bazaary_app.git
cd bazaary_app
```

### 3. تحميل الحزم
```bash
flutter pub get
```

### 4. فحص جودة الكود
```bash
flutter analyze
# المتوقع: No issues found!
```

### 5. تشغيل التطبيق (Debug Mode)
قم بتوصيل هاتفك عبر USB أو تشغيل المحاكي ثم نفّذ:
```bash
flutter run
```

## 📦 بناء حزمة الإنتاج (Production Release APK)

لإنشاء ملف APK نهائي جاهز للمشاركة والتثبيت الفوري على أي هاتف أندرويد بدون الحاجة لبيئة تطوير:

```bash
flutter build apk --release
```

يتم تصدير الملف الجاهز إلى المسار:
```text
build/app/outputs/flutter-apk/app-release.apk
```
