# 🛍️ تطبيق بازاري | Bazaary Store App

تطبيق تسوق إلكتروني متكامل مبني باستخدام إطار العمل **Flutter**، يحاكي تجربة الاستخدام في منصة "بازاري" الشهيرة بتصميم عربي أصيل (RTL) وعصري.

---

## ✨ المميزات الرئيسية (Features)

* **🎨 واجهة مستخدم عصرية (Modern RTL UI):**
  * ترويسة بتدرج لوني جذاب مع حقل بحث عائم وتحديد موقع التوصيل.
  * قائمة الفئات السريعة بصفين مع تمرير أفقي سلس.
  * بانرات إعلانية وترويجية عريضة.
  * بطاقات تفاعلية لمؤثري بازاري (مشتاق الفقية، حنان فازع...).

* **🛒 شبكة المنتجات التفاعلية (Product Grid):**
  * عرض أحدث المنتجات مع شارات الخصم (مثل: خصم 25%).
  * تقييمات بالنجوم وعدد المراجعات.
  * زر إضافة سريعة إلى السلة من الواجهة مباشرة.

* **🔍 شاشة تفاصيل المنتج (Product Details):**
  * استعراض صورة المنتج بجودة عالية.
  * شارة المنتج الأصلي ومزايا التوصيل المجاني وضمان الاستبدال.
  * مواصفات تفصيلية وزر شراء فوري.

* **🧺 سلة المشتريات الذكية (Interactive Cart):**
  * عداد ذكي (Badge Counter) على أيقونة السلة في شريط التنقل السفلي.
  * زيادة وتقليل كميات المنتجات مع حساب المجموع الفرعي ورسوم التوصيل تلقائياً.
  * إمكانية تأكيد الطلب مع نافذة تأكيد ورقم تتبع.
  * شاشة مميزة عندما تكون السلة فارغة مع زر للبدء في التسوق.

* **📑 تبويبات كاملة للتطبيق:**
  * **الفئات (Categories):** شبكة متكاملة لجميع أقسام المتجر.
  * **العروض (Offers):** كوبونات خصم قابلة للنسخ ومهرجان التخفيضات.
  * **حسابي (Profile):** بيانات العضوية، المحفظة، الطلبات النشطة، وإعدادات الحساب.

## 🏗️ هيكلية المشروع (Project Architecture)

```
lib/
├── data/
│   └── mock_data.dart            # بيانات المنتجات الافتراضية
├── models/
│   ├── cart_item.dart            # نموذج بيانات عنصر السلة
│   └── product.dart              # نموذج بيانات المنتج
├── screens/
│   ├── cart_screen.dart          # شاشة سلة المشتريات
│   ├── categories_screen.dart    # شاشة جميع الفئات
│   ├── offers_screen.dart        # شاشة العروض والكوبونات
│   ├── product_details_screen.dart # شاشة تفاصيل المنتج
│   └── profile_screen.dart       # شاشة الملف الشخصي للمستخدم
├── widgets/
│   ├── bottom_bar.dart           # شريط التنقل السفلي
│   ├── home_header.dart          # ترويسة الصفحة الرئيسية
│   └── product_card.dart         # بطاقة المنتج التفاعلية
└── main.dart                     # نقطة الانطلاق وإدارة الحالة
```

## 🚀 تشغيل المشروع (Getting Started)

1. تأكد من تثبيت بيئة **Flutter SDK**:
   ```bash
   flutter doctor
   ```
2. تثبيت الحزم والمكتبات:
   ```bash
   flutter pub get
   ```
3. تشغيل التطبيق على الهاتف أو المحاكي:
   ```bash
   flutter run
   ```
